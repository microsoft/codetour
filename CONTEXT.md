# AI-Generated Code Tours

This context defines the guided explanations generated by an AI agent to help developers understand a codebase or a set of changes.

## Language

**Project Tour**:
A guided explanation of a codebase's purpose, structure, and important execution paths for a developer discovering the project.
_Avoid_: Global tour, architecture tour

**Changes Tour**:
A guided explanation of the intent, implementation, and impact of the committed changes on a branch since it diverged from its base. Uncommitted changes are excluded unless explicitly included.
_Avoid_: Change mode, diff tour, branch tour

**Tour**:
An ordered sequence of contextual explanations attached to relevant locations in a codebase.
_Avoid_: Walkthrough file, generated documentation

**Tour Step**:
One contextual stop in a Tour, anchored to a code location or content surface and carrying a description.
_Avoid_: Comment, slide

**Tour Anchor**:
A stable location in the codebase that associates a Tour step with the code or directory it explains.
_Avoid_: Pointer, target

**Tour Generator**:
An AI agent that analyzes a workspace and proposes a Project Tour or Changes Tour through CodeTour's MCP tools.
_Avoid_: MCP client, tour writer

**Mermaid Diagram**:
A visual explanation whose Mermaid source is embedded in a Tour's explanatory Markdown and rendered by CodeTour for the reader.
_Avoid_: Schema, generated image

**Tour Workspace**:
The single project directory that a Tour Generator is allowed to inspect and in which generated Tours are persisted.
_Avoid_: Workspace root argument, current folder

**Playback Surface**:
A user-visible place where a Tour or Tour Step description is presented while reading a Tour.
_Avoid_: Component, container

**Expanded Description View**:
The side panel displaying the active Tour Step's explanation while the code retains its anchor marker.
_Avoid_: Prototype, variant A

**Tour Step Draft**:
An unsaved change to a Tour Step's explanation.

**Tour Step Conversation**:
A discussion with an agent about one Tour Step, grounded in its displayed code and explanation. Each step has its own conversation.
_Avoid_: Tour chat, workspace chat

**Step Narration**:
The optional local text-to-speech rendering of the active Tour Step's description while reading, off by default and never advancing the Tour.
_Avoid_: Voiceover, audio tour, TTS playback
